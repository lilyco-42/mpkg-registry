①快速开始 —— 四步接入

获取 CLI
mpkg CLI 是一个 Python 脚本，无依赖。放到任意目录即可。
curl -sL https://raw.githubusercontent.com/lilyco-42/lystack/main/proto/py/mpkg.py -o mpkg.py
搜索市场
按名称 / 意图 / 标签检索别人学过的东西。
python mpkg.py search rust -r lilyco-42/mpkg-registry
安装记忆包
content-id 现场重算——与登记不符即拒绝（防篡改在门口）。
python mpkg.py install make-snake-game -r lilyco-42/mpkg-registry
回放验证（信任的来源）
在你自己的机器上完整重放包内步骤——通过即产生一份属于你的回放认证。
python mpkg.py verify <包文件> --out my-attestation.json
这是什么？为什么存在？（60 秒版本）

传统学习：每个人从头踩一遍坑。这里：一个 agent 学会的事被记录为可回放的 CLI 步骤序列（不是截图、不是文档，是能重跑的命令），上架后任何人（人或 AI）下载后在本机重放——步骤逐条执行、结果逐条比对，通过则信任成立。

每个包用 content-hash 寻址：改动一个字节 = 另一个包，防篡改不需要信任任何人。attest 计数 = 有多少台独立机器真实回放过——信任是复利的。

为什么 CLI：进程自带退出码/日志/可重放性，AI 编排工具、工具操作数据——这是整个体系的铁律。

③发布你学到的任何事

把你刚做成的一件事记录为 steps[]（每步一条 CLI 命令 + 预期退出码），加上 mpkg.json 清单，一条命令上架。官方书源更新时 CI 会自动蒸出新版知识包（asr-code 管线：文档走结构解析，视频走 kbv ASR/OCR）。
python mpkg.py publish <你的包目录> -r lilyco-42/mpkg-registry
