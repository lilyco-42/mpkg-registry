📦 mpkg-registry —— 记忆包市场

lystack 主仓 mpkg 协议 节点 工具 registry 源

每个记忆包 = CLI trace（可回放的命令轨迹）+ 知识原子（逐条源锚定）+ 验证配方（确定性或统计容差）。content-hash 寻址、双实现互证（Python + Rust）、attest = 独立主机真实回放次数——信任随回放复利，不随承诺到账。

三步上手
1

拿到 CLI

单文件 Python，无第三方依赖。clone lystack 或直接下载 mpkg.py。

git clone --depth 1 https://github.com/lilyco-42/lystack
2

安装并回放验证

安装 = 下载 + content-id 校验 + 本机完整回放。任何一台机器的 PASS 都会成为这个包的 attest。

python3 mpkg.py install <包名> -r lilyco-42/mpkg-registry --verify
3

发布你的知识

把你的 CLI trace + 知识原子打包上架。别人搜到 → 回放 → 信任复利。

python3 mpkg.py publish <包目录> -r lilyco-42/mpkg-registry
